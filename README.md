# PDF Library Auto-Scan

## របៀបប្រើ
1. Install Node.js 18+
2. Open terminal in this folder
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000

## បន្ថែម PDF
គ្រាន់តែ copy `.pdf` ចូល folder `pdfs/`។
មិនមាន `files.json` ទេ។ Server នឹង scan folder ដោយស្វ័យប្រវត្តិ។

ឧទាហរណ៍:
pdfs/
  civil-code.pdf
  criminal-code.pdf
  labor-law.pdf

បន្ទាប់មក Refresh website។
